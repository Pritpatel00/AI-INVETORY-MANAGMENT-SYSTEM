# Inventory feature

This folder owns the worker and manager inventory experience.

- `InventoryApp.tsx` contains the current Milestone 1 interactive prototype.
- `data/` contains temporary demonstration records.
- `types.ts` contains frontend inventory types.

As backend development starts, the feature will be divided into:

- `components/` for reusable inventory controls;
- `worker/` for voice entry, confirmation and cycle counting;
- `manager/` for approvals, discrepancies and reorders;
- `api/` for typed backend requests;
- `hooks/` for feature state and browser capabilities.
